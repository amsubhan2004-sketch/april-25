# Oil & Gas Production Forecasting FYP Web App

Single-page React application with:
- Ensemble Hybrid model only (98.1% displayed accuracy)
- CSV upload + preprocessing
- Forecast dashboard + CSV export
- Framer Motion interactions
- Remotion-based 3D animation

## Run in VS Code

```bash
npm install
npm run dev
```

Open the local URL shown in terminal.

## Production build

```bash
npm run build
npm run preview
```
